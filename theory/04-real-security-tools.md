# 4 — Where this pattern lives in real security tools

The thing you just built — edit distance + homoglyph normalisation
+ brand list — is a baby version of what every major email security,
DNS security, and anti-phishing product does in production.

Here's the tour.

## Google Safe Browsing

The red "Deceptive site ahead!" warning Chrome shows when you click
a phishing link.

Google maintains a massive list of flagged URLs. Part of how they
find candidates to flag is **large-scale homoglyph scanning** of
newly registered domains. They compare every new registration
against their database of known legitimate brands using
edit-distance-with-homoglyphs. Flagged candidates get crawled and
reviewed.

Your Chrome blocks phishing today because of a loop like your
tool's, running at Google's scale.

## Microsoft Defender SmartScreen

Edge/IE/Office 365's anti-phishing layer. Same pattern — homoglyph
scanning on URL click, plus reputation lookup. If an email contains
a link to a domain within a few edits of a known brand it doesn't
match, SmartScreen warns the user before loading.

## Cisco Umbrella (OpenDNS)

A DNS firewall used by many enterprises (including banks in Kenya).
When a device on your corporate network tries to resolve a domain,
Umbrella checks it against:
- Known-malicious lists
- Newly-registered-domain heuristics
- **Lookalike-domain heuristics** — same edit-distance check your
  tool does, but against the enterprise's protected-brand list

If the domain is flagged, the DNS query returns a block page
instead of the attacker's IP.

## dnstwist / urlcrazy / CatPhish

Open-source tools built explicitly for the typo-squatting problem:

- **dnstwist** — generates all plausible typo-squat variations of a
  given domain (not the reverse direction our tool does), then
  checks DNS to see which ones are registered. Used by security
  teams for proactive brand monitoring.
- **urlcrazy** — similar, written in Ruby.
- **CatPhish** — similar, in Python.

Different direction, same algorithms underneath. "Generate typos"
and "detect typos" are two sides of the same problem.

## Certificate Transparency monitoring

Every TLS certificate issued by a legitimate CA is logged to public
Certificate Transparency (CT) logs. Anyone can read them in near
real time.

Security teams write scripts that:
1. Pull every new cert issued in the last hour
2. Extract the domain names on each cert
3. Compare every domain against their brand list using
   edit-distance-with-homoglyphs
4. Alert on matches

A phisher who gets a TLS cert for `paypaI.com` can't hide — CT logs
record the cert, and defenders pick it up within minutes.

Your tool is a scaled-down version of what a `crt.sh` monitoring
script does.

## Phishing report automation

Big companies (banks, telcos) have "abuse" or "phish@" inboxes.
Users forward suspicious emails there. A triage bot:

1. Extracts URLs from the forwarded email
2. For each URL, extracts the domain
3. Runs the domain through a typo-squatting detector (like yours)
4. If it matches a brand, auto-escalates to the SOC
5. If not, queues for human review

Speeds up incident response dramatically. SOC analysts work the
cases the bot pre-filters.

## Fraud detection at banks

Kenyan banks (Equity, KCB, Co-op) and mobile-money providers
(Safaricom, Airtel Money) all run some version of this monitoring.
The brand list is specific to Kenyan banking:

```
safaricom.co.ke
mpesa.com
kcbgroup.com
equitybank.co.ke
coop.co.ke
absa.co.ke
```

A lookalike like `safaric0m.co.ke` (with a zero) gets flagged,
reported to the Communications Authority of Kenya (CAK), and
eventually taken down by .ke registrars.

## Larger-scale commercial tools

- **BrandShield, Allure Security, ZeroFox** — vendors that sell
  "brand protection" as a service to Fortune 500s. Monitor CT logs,
  app stores, social media, and DNS registrations for lookalikes.
- **Infoblox, Palo Alto DNS Security, Akamai Edge DNS** — DNS
  firewall products with built-in typo-squat detection.
- **Microsoft Attack Simulator** — lets security teams simulate
  phishing campaigns, often using lookalike domains generated by
  dnstwist-style tools.

They all use edit distance under the hood. The product is the
infrastructure around it: feeds, dashboards, integrations,
takedown workflows.
